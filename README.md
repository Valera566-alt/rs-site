# rs-сайт

Разработка сайта для сервиса на Flask.

## Описание
Проект представляет собой базовый веб‑сервис. В текущей версии реализованы основные модули в файлах `app.py` и `services.py`, отвечающие за маршрутизацию и бизнес‑логику.

## Технологии
- Python
- Flask

## Установка и запуск

1. Клонируйте репозиторий:  
   `git clone https://github.com/Valera566-alt/rs-site.git`
2. Перейдите в папку проекта:  
   `cd rs-site`
3. Активируйте виртуальное окружение (у тебя оно уже есть):  
   `source venv/bin/activate`  
   (на Windows: `venv\Scripts\activate`)
4. Если появится файл `requirements.txt`, установите зависимости:  
   `pip install -r requirements.txt`
5. Запустите приложение:  
   `python app.py`

## Статус
Проект находится в активной разработке.
